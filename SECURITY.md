# Security Policy

## Supported Versions

`pytest-fakellm` is a testing utility and is published from the `main` branch.
Security fixes are applied to the latest released version. Please make sure you
are on the most recent release before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
pull requests, or discussions, as that could expose the issue to others before
a fix is available.

Instead, report them privately using one of the following:

- **GitHub:** Open a private report via the repository's
  [Security Advisories](https://github.com/1dg618/pytest-fakellm/security/advisories/new)
  page ("Report a vulnerability"). This is the preferred method.
- **Email:** `1dg618@gmail.com`

When reporting, please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a minimal proof of concept
- The affected version(s) of `pytest-fakellm`
- Any suggested mitigation, if you have one

## What to Expect

- You can expect an acknowledgement of your report within a few days.
- The maintainer will investigate and keep you informed of progress toward a
  fix.
- Once a fix is released, the issue may be disclosed publicly, and you will be
  credited for the discovery unless you prefer to remain anonymous.

Because this is a small, single-maintainer project, response times are
best-effort. Thank you for helping keep the project and its users safe.
